# 代码动画风格库 · 配图补充版

在 B 站 UP 主 [俯仰观照](https://space.bilibili.com/3690990015613855) 免费分享的代码动画风格库上补充参考图。原始资料和使用演示见[原视频](https://www.bilibili.com/video/BV1bqx76wEUM/)。

## 怎么用

下载并解压完整目录，用 Chrome 或 Edge 双击打开 [风格挑选.html](风格挑选.html)。可以离线搜索、筛选、放大图片、查看提示词和导出已选清单。请让 HTML 和 `风格提示词/` 保持相邻。

## 这次补了什么

- 根据原提示词用 ImageGen 补了 140 张参考图。341 个编号中，现在有 333 个带图。
- 有些风格靠动作、转场体现，配图采用代表帧或多格关键帧。
- M14、M15、M16、M17、M26、M35、M39、M40 的原条目没有名称和提示词，在挑选页标为「待补提示词」。
- [配图生成记录](配图生成记录.json) 提供新增图片的编号、路径和生图提示词。[说明](说明.md) 提供原库用法，[示例](示例/) 保留原库的演示。
